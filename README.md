# framealign — 跨帧率落点对齐与误差表

纯 Go（仅标准库）实现：把 24 / 25 / 30 / 29.97 fps 素材上的切点、字幕、
标记映射到声明为 25 fps 的时间线，对半帧落点给出多个可解释候选，
绝不静默取整，并导出每种取整选择的误差表。

## 合法落点规则

- 时间线合法落点 = 25 fps 的整数帧边界（40 ms 栅格）。
- 源帧 `n` 的时间线位置 = `n × 25 / srcFps`（有理数精确计算，
  29.97 严格按 30000/1001，不用浮点近似）。
- 各源帧率重新精确对齐的周期（每多少源帧出现一次合法落点）：

| 源帧率 | 周期 | 含义 |
| --- | --- | --- |
| 25 | 1 帧 | 恒精确 |
| 30 | 6 帧 | 每 0.2 s 精确一次 |
| 24 | 24 帧 | 每 1 s 精确一次 |
| 29.97 | 1200 帧 | 每 40.04 s 精确一次 |

- 29.97 时间码按 NTSC drop-frame 解析（`HH:MM:SS;FF`），被丢弃的
  标签（非 10 分钟整点的 `:00`/`:01` 帧）视为非法输入。

## 半帧候选策略

落点非整数帧时生成三个可解释候选，由人选择，不自动取整：

- `floor`：向早取整，落点不晚于创作意图点（切点不提前截断上一镜头）。
- `ceil`：向晚取整，落点不早于创作意图点（字幕出点不提前消失）。
- `nearest`：绝对误差最小；恰半帧时向偶数帧取整（round-half-to-even，
  消除长片累积偏置）。

## 用法

```sh
go run ./cmd/framealign                      # 内置演示事件集
go run ./cmd/framealign -events events.csv   # 自定义事件
go test ./...                                # 测试
```

事件 CSV 格式：`kind,label,src_fps,position`，其中 `kind` ∈
`cut|subtitle-in|subtitle-out|marker`，`position` 为源帧号或时间码。

输出（默认 `artifacts/`）：

- `candidates.csv`：事件 × 候选全量误差表（含精确帧位置、各候选的
  帧号、帧分数误差与毫秒误差）。
- `summary.csv`：每种策略的事件数、调整数、最大/均值/RMS 误差。
- `report.md`：上述两表的 Markdown 版，附候选说明。
